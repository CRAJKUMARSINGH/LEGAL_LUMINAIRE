- **Node.js 22+** (with corepack enabled for pnpm 10)
- **Python 3.11+** *(only for the optional AI backend — the frontend demo mode runs without it)*

### Step 2 — Clone + Install

```powershell
# Windows (PowerShell)
git clone https://github.com/CRAJKUMARSINGH/legal-luminaire.git
cd legal-luminaire
corepack enable
corepack prepare pnpm@10 --activate
pnpm install --frozen-lockfile
```

```bash
# macOS / Linux (bash)
git clone https://github.com/CRAJKUMARSINGH/legal-luminaire.git
cd legal-luminaire
corepack enable
corepack prepare pnpm@10 --activate
pnpm install --frozen-lockfile
```

---

### Step 3 — Run the Frontend (Local Demo Mode, No API Keys)

```powershell
# Windows (PowerShell)
pnpm --filter @workspace/legal-luminaire run dev
```

```bash
# macOS / Linux (bash)
pnpm --filter @workspace/legal-luminaire run dev
```

### Step 4 — Open the App + Load the Demo

Open **http://localhost:5173** in your browser → click the big **🎬 Demo Mode** button on the dashboard.

The `CASE01_HEMRAJ_STATE_2025` (Hemraj Vardar, Stadium Collapse / Forensic Masonry) case loads automatically. **You're done.** You can now:

- Browse the timeline
- Run case-law research

- Generate a print-ready discharge application in English *and* Hindi

## 📖 How to Use

### 🅰 Workflow: Run the Hemraj Stadium-Collapse Demo

1. From the dashboard, click **🎬 Demo Mode** (or navigate to `/demo-browser`).
2. Select **CASE01_HEMRAJ_STATE_2025** from the case pack.
3. The 4-step guided workflow activates:
   - **Intake** (`/intake`) — review the auto-parsed FIR, charge-sheet, and FSL report stub.
   - **Research** (`/case-law`) — browse the pre-loaded, tier-verified case law matrix.
   - **Drafting** (`/discharge-application`) — one-click generate the Hemraj discharge v5.
   - **Review** (`/verification-report`) — inspect the Verification Report + Pre-Filing Checklist.
4. Hit **Print / PDF** on `/discharge-application-print` for a court-ready PDF.

### 🅱 Workflow: Generate a Discharge Application

1. Load **any** case (demo cases all have a `DischargeApplication` route registered, or load your own via `/intake`).
2. Navigate to the **Drafting** group in the sidebar → **Discharge**.
3. Review the Citation Gate panel — any `PENDING` / `FATAL_ERROR` citations will be **strikethrough-blocked** and listed in the audit panel before the draft renders.
4. Click **Generate Draft**. The output ships with:
   - Full VERIFIED / SECONDARY tier badges inline
   - A **Verification Report** appendix
   - A **Pre-Filing Checklist** (filing date, court seal, annexure index, Para 1–6 compliance check)
5. Print via the `/discharge-application-print` route (court CSS with page numbers).

### 🅲 Workflow: Use the Citation Verification Gate + Cross-Ref Matrix

1. With a case loaded, open the sidebar → **Research** group → **Cross-Ref Matrix** (`/cross-reference`).
2. The matrix rows are charges; columns are (a) Statute citations, (b) Case-law citations, (c) Standards citations (IS/ASTM/NABL), (d) Fact-fit score.
3. Any cell showing a **PENDING** or **FATAL_ERROR** badge is:
   - **Auto-blocked from all draft output** (see `/safe-draft`)
   - **Auditable** in the Verification Report (`/verification-report`)
4. Click the **Standards Index** (`/standards-index`) for the full IS/ASTM/NABL reference library — including the Hemraj IS 2250:1981 vs IS 1199:2018 guard rule.

### 🅳 Workflow: Switch Between the 26 Demo Cases

1. Click **All Cases** in the sidebar or the **case chip** in the header.
2. The global Case Selector opens. Filter by type:
   - **Criminal** (13): Bail / Discharge / NDPS / NI Act / POCSO / Arms Act / Murder / GST / Cyber Fraud
   - **Civil** (4): Writ (Land Acquisition / Service / Environment) / Landlord-Tenant / Insurance / Contract / Election
   - **Infra-Arbitration** (5, real-case style packs): Highway / Dam / Substation / Hospital / Landscape Township
3. One click = full context swap. All routes (timeline, cross-ref, discharge, copilot, deadlines) instantly re-scop to the newly-selected case.

### ✅ Non-Negotiable Accuracy Rules (Quick Reference)

| Tier | Meaning | Allowed in Drafts? |
|---|---|---|
| `COURT_SAFE` | Certified copy + para number confirmed | ✅ Always |
| `VERIFIED` | Confirmed on official source | ✅ Always |
| `SECONDARY` | Credible secondary source | ⚠️ With qualification note |
| `PENDING` | Unverified | ❌ **BLOCKED** from all draft output |
